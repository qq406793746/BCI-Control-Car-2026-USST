# tools

这个目录放辅助工具脚本。

当前主要包含：

- `lsl_relay_with_eog.py`
  LSL/链路延迟相关辅助脚本
- `xdf_lsl_sender.py`
  从 XDF 推流到 LSL 的工具
- `lsl_socket_relay_25ch.py`
  LSL relay 相关脚本
- `run_xdf_simulation.py`
  基于 XDF 的离线仿真推理工具
- `validate_data_loading.py`
  数据加载与通道检查脚本
- `check_artifacts.py`
  模型产物检查脚本

这些文件通常不属于仓库首页主线，但保留后续排查会更方便。
